# Thoughtbot Blog Clone

A static front-end recreation of the thoughtbot blog landing page, built with HTML and CSS.

## Live demo

Visit the deployed site: [though-bot.vercel.app](https://though-bot.vercel.app/)

## Features

- thoughtbot-inspired blog header, navigation, and footer
- Blog introduction, topic links, and article previews
- Newsletter signup form layout
- Pagination controls
- Interactive hover styles

## Built with

- HTML
- CSS
- Font Awesome icons
- Google Fonts

## Run locally

No build tools or package installation are required. Clone the repository and open `index.html` in a browser, or serve the project directory with a local static web server.

The page loads Font Awesome and Google Fonts from their CDNs, so an internet connection is needed for those assets.
